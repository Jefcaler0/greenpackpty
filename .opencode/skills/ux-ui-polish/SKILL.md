# UX UI Polish

Use this skill when the task is about improving visual quality, interaction quality or usability.

## Design Direction

- Brand tone: sustainable, clean, warm, professional and academic-portfolio friendly.
- Visual language: pastel greens, cream neutrals, soft clay accents, rounded product cards and calm spacing.
- The page should feel like a polished corporate product landing page, not a generic template.

## UX Priorities

- Make the required academic sections easy to identify:
  - Quiénes somos.
  - Qué hacemos.
  - Productos y servicios.
  - Misión, visión y valores.
  - Ubicación.
  - Contacto y redes sociales.
- Keep primary actions obvious: catalog browsing and contact.
- Avoid duplicating content across sections.
- Keep text concise and scannable.

## Accessibility Checklist

- Color contrast should be readable on pastel backgrounds.
- Focus states must remain visible.
- Links and buttons should have at least 44px touch targets.
- Images need descriptive `alt` text.
- Embedded maps need a clear `title` and accessible surrounding copy.

## Visual Quality Checklist

- Maintain symmetry in grids and footer columns.
- Use consistent image treatment: border radius, object-fit and spacing.
- Avoid overly dark shadows on pastel surfaces.
- Keep footer structured and balanced across desktop and mobile.
- Prefer product imagery that feels clean, catalog-like and relevant.

## Review Response Pattern

When reviewing UI, report issues in this order:

1. Blocking usability or accessibility issues.
2. Visual hierarchy and layout issues.
3. Copy clarity issues.
4. Optional polish opportunities.
