# Marketing Landing

Use this skill for positioning, landing page structure and marketing copy.

## Page Purpose

This project is a corporate example site for GreenPack Panamá, built for a class portfolio. The page should explain the brand and products clearly so it can work as a destination page for digital promotion.

## Required Content Coverage

Ensure the page answers these points clearly:

- Quiénes somos.
- Qué hacemos.
- Productos y servicios, with one or two key products maximum.
- Por qué el público escoge la marca: clear value proposition.
- Misión, visión y valores.
- Datos de contacto and social links.

## Copy Principles

- Write in clear Spanish for a Panamanian audience.
- Keep claims practical and believable.
- Avoid unsupported metrics or exaggerated sustainability claims.
- Prefer concrete benefits: resistencia, compostabilidad, presentación, delivery, personalización, stock local.
- Keep CTAs direct: `Solicitar cotización`, `Ver catálogo`, `Escribir por WhatsApp`.

## Product Focus

The main products are:

- Envases de caña de azúcar.
- Vasos de PLA.

Keep product copy detailed enough to support a future campaign, but avoid overcrowding the landing page.

## SEO And Metadata

- Title should include `GreenPack Panamá` and `empaques sostenibles`.
- Description should mention biodegradable/sustainable packaging and gastronomy.
- Avoid keyword stuffing.
- Keep Open Graph copy consistent with page content.

## Quality Check

Before delivery, confirm:

- Each required academic criterion is visible or intentionally represented.
- Product claims match the page's product cards.
- CTA labels match the user's intended action.
- Contact placeholders are easy to replace with real data.
