# GreenPack Web

Landing corporativa en React/Vite para un portafolio académico de GreenPack Panamá.

## Propósito de la página

El propósito del sitio es presentar una página corporativa de ejemplo para GreenPack Panamá, una marca enfocada en empaques biodegradables y sostenibles para gastronomía.

La página muestra de forma clara quiénes somos, qué hacemos, productos principales, misión, visión, valores, ubicación y datos de contacto.

## Contenido principal

- Quiénes somos y qué hacemos.
- Galería de empaques biodegradables.
- Dos productos principales: envases de caña de azúcar y vasos de PLA.
- Servicios asociados: asesoría, reposición programada, guía de uso y personalización.
- Información para restaurantes, cafeterías, dark kitchens y catering.
- Misión, visión y valores corporativos.
- Ubicación referencial con Google Maps.
- Contacto y enlaces a redes sociales.

## Stack tecnológico

- React
- Vite
- CSS personalizado
- Vercel para despliegue

## OpenCode skills

El proyecto incluye skills locales compatibles con OpenCode en `.opencode/skills`:

- `frontend-react`: implementación y revisión de React, Vite y CSS.
- `ux-ui-polish`: mejoras de interfaz, accesibilidad, responsive y calidad visual.
- `marketing-landing`: copy, posicionamiento, contenido corporativo y preparación de landing page.

La configuración está en `opencode.json`. Reinicia OpenCode después de modificar estos archivos para que la sesión cargue los cambios.

## Desarrollo

```bash
npm install
npm run dev
```

## Build para Vercel

```bash
npm run build
```

Vercel detecta Vite automáticamente. El directorio de salida es `dist`.

## Nota académica

Este proyecto fue desarrollado como portafolio de ejemplo para trabajo de clase. Los datos de contacto, redes sociales y ubicación pueden ser reemplazados por información real antes de un despliegue público.
