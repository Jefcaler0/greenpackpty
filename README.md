# GreenPack Web

Landing corporativa en React/Vite para un portafolio académico de GreenPack Panamá.

## Propósito de la página

El propósito del sitio es presentar una página corporativa de ejemplo para GreenPack Panamá, una marca enfocada en empaques biodegradables y sostenibles para negocios gastronómicos B2B.

La página funciona como pieza de apoyo para una campaña digital, mostrando de forma clara quiénes somos, qué hacemos, productos principales, oferta de valor, misión, visión, valores, ubicación y datos de contacto.

## Contenido principal

- Quiénes somos y qué hacemos.
- Galería de empaques biodegradables.
- Dos productos principales para campaña: envases de caña de azúcar y vasos de PLA.
- Servicios asociados: venta por mayor, asesoría, abastecimiento recurrente y personalización.
- Oferta de valor para restaurantes, cafeterías, dark kitchens y catering.
- Misión, visión y valores corporativos.
- Ubicación referencial con Google Maps.
- Contacto comercial y enlaces a redes sociales.

## Stack tecnológico

- React
- Vite
- CSS personalizado
- Vercel para despliegue

## Desarrollo

```bash
npm install
npm run dev
```

## Build para Vercel

```bash
npm run build
```

Vercel detecta Vite automáticamente. El directorio de salida es `dist`.

## Nota académica

Este proyecto fue desarrollado como portafolio de ejemplo para trabajo de clase. Los datos de contacto, redes sociales y ubicación pueden ser reemplazados por información real antes de un despliegue comercial.
